# 网络位置、Windows 设备列表与 SMB 实施方案

> 日期：2026-09-01
> 状态：方案已确认，等待实施
> 对应 Issue：[GitHub Issue #10](https://github.com/LiuYangArt/AsterFiles/issues/10)

## 1. 目标

AsterFiles 在侧栏增加两个语义和生命周期明确分离的区域：

1. **网络位置**：用户保存或从 Windows Explorer 导入的常用远程路径，未来统一容纳 SMB、SFTP、WebDAV 等协议位置；
2. **网络**：Windows 当前发现的局域网设备列表。

侧栏只负责发现设备和提供入口，不承担远程目录树。点击设备后，在当前标签打开该设备的 Windows 网络根位置，由主内容区显示真实共享列表；进入共享以后继续使用现有标签目录导航。

首个实施版本完整支持 SMB/UNC 的浏览、打开、复制、移动、重命名、删除和拖放。核心体验红线是：NAS 缓慢、离线、认证失败或 Windows 网络调用长时间不返回时，AsterFiles UI、本地磁盘浏览和其他设备访问仍保持可用。

## 2. 已确认的产品决策

- “网络位置”和“网络”必须是两个独立侧栏分组，不合并、不互相自动转化；
- “网络位置”导入 Windows Explorer 已保存的 Network Locations；
- AsterFiles 自有的网络位置与 Windows 导入项统一展示，但保留来源和所有权；
- “网络”只显示 Windows 发现的局域网设备，不提供“手动添加设备”；
- Windows 未发现但地址已知的设备，可通过 UNC 路径保存为“网络位置”，不会注入“网络”设备列表；
- 侧栏不展开设备内部的共享或文件夹，不保存设备内部展开状态和目录快照；
- 点击设备名称，在当前标签打开设备根位置；共享和目录结构只在主内容区浏览；
- 首期完成 SMB 的完整文件管理能力，不交付只能浏览的临时版本；
- SFTP、WebDAV、FTP、S3 等协议不在本 Issue 实现，只保留不会阻塞未来接入的目标身份边界；
- SMB 认证复用 Windows 登录会话、现有 SMB 连接和 Windows 凭据管理器，AsterFiles 不保存明文密码。

## 3. 概念边界

| 概念 | 含义 | 数据来源 | 是否持久化 | 展示位置 |
|---|---|---|---|---|
| 网络位置 | 用户明确保存的常用目标 | Explorer Network Locations 或 AsterFiles 收藏 | 是 | 侧栏扁平快捷入口 |
| 网络设备 | 当前 Windows 发现的计算机、NAS 等设备 | Windows 网络命名空间 | 否 | 侧栏设备列表 |
| 设备根 | 某设备当前可访问的共享集合 | 点击设备后后台枚举 | 否 | 当前标签主内容区 |
| 共享与目录 | SMB 共享及其真实内容 | 标签目录导航 | 否 | 当前标签主内容区 |
| 凭据 | Windows SMB 会话使用的账号信息 | Windows 会话与凭据管理器 | 由 Windows 管理 | 不直接展示秘密 |

“网络位置”回答“我经常去哪里”；“网络”回答“Windows 当前发现了哪些设备”。同一设备或路径同时出现在两处是合理结果：前者是快捷入口，后者是动态设备入口。

### 4.1 网络位置

- 扁平列表，按用户顺序展示，不把路径拆成树；
- Windows 导入项使用 Explorer 的显示名称和图标；
- AsterFiles 自有项允许自定义名称；
- SMB 项点击后在当前标签导航到原始 UNC 路径；
- 未来协议项点击后由对应协议提供者打开；
- 未连接、离线或需要登录不会导致启动时探测，只有用户点击后才建立连接；
- 当前路径提供“添加到网络位置”；
- 右键操作：在新标签打开、重命名、复制地址、管理凭据、移除；
- Windows 导入项执行重命名或移除前明确提示会同步影响 Explorer；AsterFiles 自有项只修改自身配置。

### 4.2 网络

- 分组展开时才启动 Windows 设备发现，不在应用启动关键路径执行；
- 侧栏分组内只显示 Windows 返回的设备，不显示设备下的共享或文件夹；
- 点击设备名称，在当前标签打开设备根位置，例如 `\\LiuYanghomeNAS`；
- 主内容区后台枚举并分批显示该设备的共享；双击共享后按普通目录进入；
- 分组折叠或刷新会取消仍在运行的设备发现，并拒收迟到结果；
- 设备列表不进入会话持久化，下次展开时重新读取 Windows 当前发现结果；
- 设备右键操作：打开、在新标签打开、刷新设备列表、复制设备地址、添加设备根到网络位置；
- 不提供“隐藏发现设备”或“手动添加设备”，避免建立第二份设备清单。

图中设备名前的箭头不是当前功能的一部分；实现采用普通侧栏行，避免暗示侧栏可以继续展开。只有“网络”分组标题本身可以展开或折叠。

## 5. Windows Network Locations 导入

使用 Windows Shell 的 Network Shortcuts/NetHood 命名空间作为导入来源，不直接依赖目录布局或手工解析 `desktop.ini`、快捷方式文件。

导入规则：

- 每次启动或用户刷新“网络位置”时在后台重新枚举；
- 不把导入项复制进 AsterFiles 自有配置，避免产生两份可漂移记录；
- 为每项保留稳定来源身份、显示名称、Shell 图标和可解析目标；
- 能解析为本地路径或 UNC 的项目由 AsterFiles 直接浏览和操作；
- 只有 Shell 虚拟身份、无法得到文件系统目标的项目仍可展示，但点击时交给 Windows 打开，并明确不具备 AsterFiles 内部文件操作能力；
- Windows 项的重命名和删除属于外部状态修改，必须明确说明会影响 Explorer；
- AsterFiles 自有项与导入项即使目标相同也保留各自来源，首期不设计复杂合并规则。

## 6. Windows 设备发现与设备根导航

### 6.1 发现来源

“网络”分组以 Windows 网络命名空间返回的设备为唯一来源。AsterFiles 不实现独立的 WS-Discovery、NetBIOS、mDNS 或端口扫描，也不维护手动设备清单。

Windows 发现受“网络发现”系统设置、防火墙、网络配置文件、设备协议和子网边界影响，因此产品文案使用“Windows 发现的设备”，不承诺列出局域网全部设备。发现不到但已知地址的目标只能通过地址栏或“网络位置”访问。

### 6.2 数据流

```text
展开“网络”分组
  → 后台枚举 Windows 发现设备
点击设备
  → 当前标签开始导航到设备根
  → 后台认证并枚举设备共享
  → 主内容区分批显示共享
双击共享
  → 复用普通 UNC 目录导航
```

设备发现请求属于窗口侧栏，至少携带 `WindowId + DiscoveryRequestId`。设备根和共享目录的内容加载属于标签，继续使用既有 `TabId + RequestId`。折叠、刷新、窗口关闭会取消设备发现；导航、关闭标签和退出会取消标签目录请求。两种迟到结果不得互相污染。

设备根是合法的 Windows 网络/Shell 位置，但未必能直接表示为普通可枚举 `PathBuf`。应用协调层必须保留设备的原始 Windows/Shell 身份及可用 UNC 地址；不能从显示名称拼接网络路径。若 Windows 能提供文件系统 UNC，则沿用原始 `PathBuf/OsString`；否则设备根使用稳定 Shell 身份，主内容区条目仍保留可执行目标身份。

## 7. SMB 认证

认证优先级：

1. 使用 Windows 当前登录身份；
2. 复用 Windows 已建立的 SMB 会话；
3. 使用 Windows 凭据管理器保存的凭据；
4. 认证失败后，由 AsterFiles 显示当前页面内的登录界面，再调用 Windows WNet 接口建立连接。

“记住凭据”交给 Windows 凭据管理器；不勾选时只建立当前 Windows 登录会话内的临时连接。AsterFiles 的配置和日志不得保存密码。

当同一服务器已有另一账号的 SMB 会话并返回凭据冲突时：

- 说明已有连接会影响本次登录；
- 不静默断开 Windows 连接；
- 只有用户明确确认后才断开该服务器的已有连接并重新认证；
- 提示该操作可能同时影响 Explorer 和其他软件。

登录、连接、断开和凭据检查全部在后台执行，不能弹出阻塞整个应用消息循环的系统对话框。

## 8. SMB 完整文件能力

首期 SMB/UNC 与本地文件共享现有用户操作语义：

- 浏览设备根、共享和目录，支持刷新、后退、前进和地址栏导航；
- 双击打开文件、共享和目录；
- 新建文件夹、重命名、删除、永久删除；
- 本地与 SMB 之间、SMB 与 SMB 之间的复制和移动；
- 剪切、复制、粘贴；
- 从 Explorer 拖入、拖出到 Explorer、AsterFiles 内部拖放；
- 冲突处理、进度、暂停、取消、部分完成和失败重试；
- 操作完成后只刷新受影响的标签。

Windows 文件系统路径继续以 Rust `PathBuf/OsString` 保存，展示字符串不得承担操作身份。映射盘如可解析，应规范到真实 UNC 身份，避免同一目标因盘符和 UNC 形成两套操作判断。

目录监听不得假设所有 NAS 都可靠支持 `ReadDirectoryChangesW`。监听不可用或断开时退化为显式刷新与操作完成后的定向刷新，不做高频轮询。

## 9. 慢网络隔离

仅把 SMB 调用移到普通后台线程不足以满足目标：Windows 同步调用可能在设备发现、共享枚举、目录枚举、属性读取、Shell 图标或文件操作中长时间不返回，当前共享目录线程也可能被多个坏共享占满。

必须采用以下隔离：

- 本地目录、SMB 目录、Windows 设备发现、Shell 图标/缩略图和文件操作使用独立有界队列；
- SMB 请求不得占用本地目录工作池；
- 每台设备限制并发，单台离线 NAS 不能耗尽全部网络槽位；
- 新导航、折叠“网络”分组、关闭标签和退出立即取消逻辑请求并拒收迟到结果；
- 首批列表不等待每项附加属性；优先使用共享或目录枚举已经返回的名称、类型、大小和时间；
- SMB 默认不主动计算文件夹大小，不预取缩略图，不解析整目录快捷方式；可见项附加信息进入独立低优先级队列；
- 网络错误区分认证失败、权限不足、主机不可达、连接超时、读取超时、共享不存在、断开和普通协议错误；
- 自动重试最多一次，用户明确刷新不受此限制；禁止无限重连。

### 9.1 逻辑取消与物理终止

首个原型必须实测 Windows 设备发现与 SMB 调用的取消边界。若关闭枚举句柄或取消 I/O 仍不能在目标时间内返回，则正式实现必须把可能永久阻塞的发现、共享枚举、目录枚举或属性调用放进可终止的辅助进程。主应用到达时间上限后放弃该进程并显示可重试状态；不能通过无限增加 Rust 线程掩盖泄漏。

初始体验门槛：

- 用户切换到本地标签后，界面在 100ms 内恢复正常交互；
- 取消发现或导航请求后，迟到结果 100% 被拒收；
- 单台坏 NAS 不影响本地目录首批显示；
- 多台坏设备不能占满所有网络执行能力；
- 2 秒无首批结果时显示“连接较慢”；
- 10 秒无目录结果时结束本次逻辑等待并提供重试；
- 具体阈值由真实 NAS、断网和限速实验调整并记录在性能产物中。

## 10. 状态与错误交互

### 10.1 侧栏设备列表

- 未加载：只显示“网络”分组标题，不访问网络；
- 发现中：分组内显示轻量加载状态，已到达设备立即追加；
- 无设备：显示“未发现设备”，不解释为局域网确实为空；
- 发现失败或超时：显示“无法获取设备 / 重试”，其他侧栏分组保持可用；
- 设备行：使用 Windows 名称和图标；点击后立即创建标签导航状态，连接进度在内容区表达；
- 当前标签正在显示某设备根时，对应设备行使用选中样式。

### 10.2 内容页

- 设备根加载中：先显示路径和加载状态，共享到达后分批追加；
- 需要登录：在内容页显示账号、密码和“记住凭据”；
- 离线、超时、权限不足：使用现有错误页语义并提供重试、登录或返回；
- 失败导航保留目标身份，不让失败结果覆盖其他标签；
- 登录成功后为同一标签生成新请求，不复用失败请求。

## 11. 数据模型与模块边界

建议最小模型：

- `NetworkLocationId`：稳定收藏身份；
- `NetworkLocationSource`：`WindowsImported` 或 `AsterOwned`；
- `NetworkTarget`：首期包含 `WindowsPath(PathBuf)` 和 `ShellItemId`，未来再增加协议目标；
- `NetworkDeviceId`：Windows 返回的稳定设备身份；
- `NetworkDeviceTarget`：设备的原始 Shell 身份与可选 UNC 地址；
- `DiscoveryRequestId`：当前窗口设备发现代次；
- `PageSource::NetworkRoot`：设备根内容页来源，继续受 `TabId + RequestId` 管理；
- `RemoteCapabilities`：浏览、读、写、重命名、删除、服务器内移动、流式传输等能力声明，仅在新增非 SMB 协议时实现。

模块分层：

```text
Slint 侧栏设备列表、网络位置与内容页状态
        ↓ 意图 / 展示模型
应用协调层：窗口发现请求、标签请求、迟到结果隔离
        ↓
网络位置目录：Windows 导入 + AsterFiles 自有收藏
设备发现：Windows 网络命名空间
        ↓
platform/windows：Shell、WNet、凭据和 UNC 系统调用
fs / OperationManager：共享、目录浏览与完整文件操作
```

UI 不调用 `exists`、`is_dir`、目录枚举、Shell、WNet、凭据或网络 API。Windows/SMB 实现集中在 `platform/windows`；未来协议实现不能散落进 UI 或把 URI 塞进 `PathBuf`。

## 12. 持久化

- Windows 导入项不进入 AsterFiles 持久化文件，每次从 Windows 读取；
- AsterFiles 自有网络位置保存稳定 ID、显示名称、排序和带类型的目标身份；
- 不保存密码、连接句柄、登录状态、设备发现结果、设备列表或运行中的请求；
- 会话格式需要升级时直接写入新格式，不保留旧格式迁移和兼容层；
- 未来 SFTP/WebDAV 凭据只保存 Windows 凭据管理器中的引用身份，不保存秘密本身。

## 13. 实施切片

### N0：阻塞与取消实证

- 使用真实 NAS、限速、断网和错误凭据测量 Windows 设备发现、共享枚举、目录枚举、属性读取和取消；
- 验证普通线程、关闭句柄、取消 I/O 的实际边界；
- 若无法满足终止门槛，先建立辅助进程隔离，再进入功能实现；
- 产出耗时、取消延迟、线程/进程数量和本地标签响应指标。

### N1：网络位置与 Explorer 导入

- 侧栏增加独立“网络位置”分组；
- 后台枚举 Windows Network Locations；
- 增加 AsterFiles 自有网络位置、排序和来源边界；
- 支持从当前 UNC 路径添加、打开、重命名、移除和管理凭据；
- Windows 项的外部修改影响必须明确提示。

### N2：Windows 发现设备列表

- 增加独立“网络”分组；
- 分组展开时后台发现 Windows 设备，分批追加设备行；
- 点击设备后在当前标签打开设备根；
- 侧栏不展开共享或文件夹；
- 完成发现代次、折叠取消、刷新、错误状态和无持久化。

### N3：设备根、SMB 浏览与认证

- 设备根在主内容区分批显示共享，双击后进入普通 UNC 目录；
- UNC 导航进入独立 SMB 目录执行队列；
- 复用 Windows 会话与凭据管理器；
- 完成登录、记住凭据、凭据冲突和重新连接；
- 首批分批显示，附加属性延迟加载；
- 覆盖快速导航、多标签、多设备和迟到结果。

### N4：完整文件操作与互操作

- 补齐 SMB 新建、重命名、删除、复制、移动、剪贴板和拖放；
- 本地与 SMB、不同 SMB 位置之间复用任务中心；
- 独立网络操作限额，不阻塞本地操作；
- 目录监听不可用时定向刷新；
- 覆盖冲突、取消、部分完成、断线与重试。

### N5：稳定性与人工验收

- 完成无界面状态场景、日志和性能产物；
- 用户在真实 Windows 11 与 NAS 环境完成侧栏、内容页、认证和 Explorer 互操作验收；
- 验收前只构建 Debug；用户确认 Issue 完成后再构建 Release。

## 14. 验证矩阵

自动验证至少覆盖：

- 网络位置两种来源、排序、重命名和移除所有权；
- Windows 导入项不可解析、失效和刷新；
- 设备发现分批、折叠、刷新、空结果和过期结果；
- 侧栏设备行没有子节点，点击产生正确设备根目标；
- 应用重启后不恢复旧设备列表；
- `WindowId + DiscoveryRequestId` 与 `TabId + RequestId` 互不污染；
- 设备根共享分批、SMB 错误分类和最多一次自动重试；
- 多台坏设备不占用本地目录执行能力；
- 凭据复用、需要登录和凭据冲突状态；
- 本地/SMB 复制移动的冲突、取消和部分完成；
- 原始 UNC/Shell 身份、非 Unicode 损失和长路径；
- 简体中文、英文与无障碍名称完整。

- Windows 网络发现开启、关闭和防火墙阻断；

## 16. 非目标

- 首期不实现 SFTP、FTP、WebDAV、S3 或云盘协议；
- 不自行实现 SMB 协议栈；
- 不实现独立局域网扫描或手动设备清单；
- 不把 Windows 未发现但可访问的 UNC 主机注入“网络”列表；
- 不在侧栏展开设备共享或文件夹树；
- 不保存设备发现结果或设备列表快照；
- 不在启动时连接、认证或探测每个网络位置；
- 不对未索引网络目录递归计算文件夹大小；
- 不用显示字符串反向构造远程身份；
- 不为未来协议预先实现空壳提供者框架。

## 17. 完成标准

只有同时满足以下条件才可关闭 Issue：

- “网络位置”和“网络”的语义、来源和交互符合本文；
- Explorer Network Locations 可导入，AsterFiles 自有收藏可管理；
- “网络”展开后显示 Windows 发现设备，设备不含侧栏子树；
- 点击设备在当前标签打开设备根并分批显示共享；
- SMB 完整文件操作、认证、凭据冲突和 Explorer 拖放通过真实验证；
- 慢 NAS、断网和多个坏共享不会冻结 UI、阻塞本地导航或无限消耗后台线程；
- 自动验证、Debug 构建、状态、日志和性能产物齐全；
- 用户完成真实 UI 验收并明确确认后，按项目规则构建 Release 并记录时间与 SHA-256。
