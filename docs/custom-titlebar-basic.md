# 自定义标题栏基础版设计

> 日期：2026-08-28  
> 状态：实施基线  
> 范围：Windows 桌面端标签区与窗口标题栏合并

## 目标

将标签区移入自绘标题栏，释放原生标题栏占用的垂直空间，并把低频功能移出顶部高价值区域。基础版优先保证可用、清晰和现有标签状态不被破坏；Windows 11 原生贴靠布局等系统级一致行为后置。

## 布局

顶部第一行改为约 48px 高的自定义标题栏，并在标签上方保留 5px 呼吸空间：

1. 不显示 `AsterFiles` 文字 Logo；
2. 标题栏最左侧增加菜单按钮，菜单提供设置入口；
3. 菜单按钮之后显示标签，每个标签保留目录图标、标题和加载状态；
4. 标签之后只保留“新建标签”按钮；
5. 中间剩余空白区域用于拖动窗口，双击切换最大化/还原；
6. 右侧放最小化、最大化/还原、关闭窗口按钮；
7. 删除顶部独立的关闭标签、恢复标签、刷新标签和语言按钮；
8. 语言切换从侧栏移入设置页；侧栏不再保留语言按钮。

地址栏继续作为第二行。导航区中的刷新按钮属于高频目录导航，继续保留；本次删除的是标签栏末尾的独立恢复/刷新样式按钮。

## 标签交互

- 左键单击标签主体：切换标签；
- 标签可关闭时，鼠标悬停该标签才显示右侧关闭按钮；
- 左键单击标签内关闭按钮：关闭该标签，不要求先激活；
- 鼠标中键单击标签任意位置：关闭该标签；
- 只剩一个标签时不允许关闭，关闭按钮不显示，中键不生效；
- `Ctrl+W` 继续关闭当前标签，`Ctrl+T` 继续新建标签；
- 关闭非当前标签时保持当前标签；关闭当前标签时激活相邻标签；
- 关闭标签必须取消该标签尚未完成的目录任务，并继续进入现有“恢复关闭标签”栈。基础版不再提供可见恢复按钮，恢复入口后续随标签菜单设计补回。

## 窗口行为

基础版使用无原生边框窗口，并保留可调整尺寸边缘。需要支持：

- 拖动标题栏空白区移动窗口；
- 双击空白区最大化或还原；
- 最小化、最大化/还原、关闭窗口；
- 最大化后可正常还原，窗口位置和尺寸继续由现有会话逻辑保存。
- 在窗口创建前设置 Windows 11 系统圆角偏好、无边框阴影和无原生装饰，避免窗口显示后设置被 DWM 忽略；缩放命中区向窗口内部扩至 10px，不依赖鼠标精确压在最外侧像素。

本阶段明确不实现：Windows 11 最大化按钮悬停贴靠浮层、完整原生非客户区命中测试、系统主题下完全一致的标题栏动画和菜单。

## 响应式约束

- 窄窗口沿用现有标签宽度降级；窗口控制按钮区域不可被标签挤占；
- 标签数量超出可用宽度时，基础版允许标签继续压缩到现有最小宽度策略的能力边界，不在本次引入标签滚动或溢出菜单；
- 左侧菜单按钮始终保留；设置页中的主题和语言入口不依赖侧栏是否可见。

## 验收

- 原生标题栏消失，标签与窗口按钮位于同一行；
- 顶部不再出现 `AsterFiles` Logo、独立关闭标签、恢复标签和语言按钮；左侧菜单可进入设置页；
- 标签关闭按钮仅悬停显示，能关闭被点击的标签；
- 中键关闭标签有效，最后一个标签不可关闭；
- 标签空白区拖动、双击最大化/还原及三个窗口按钮有效；
- 设置页可修改主题和语言，选择可保存；侧栏不再显示语言切换；
- 地址栏刷新与 `F5` / `Ctrl+R` 不受影响；
- 通过 `cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings`、`cargo test` 和 `cargo build --release`；
- Release 程序完成一次人工可见 UI 检查，验证后不残留后台进程。
