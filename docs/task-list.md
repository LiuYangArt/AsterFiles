# AsterFiles 开发任务清单

> 原则：先把本地文件管理做成可靠的日用工具，再扩展高级能力。性能专项验证暂缓，但所有阶段继续遵守“UI 线程不做磁盘工作、列表虚拟化、可取消、可见区域优先”。

前期架构切片与验收见 [foundation-plan.md](foundation-plan.md)。UI 结构、交互状态、图标边界和 P0 逐项验收见 [ui-interaction-design.md](ui-interaction-design.md)。F0–F4 已完成首个端到端版本，后续功能沿用每标签独立状态和统一 UI 意图边界。

## P0：可日用的浏览闭环

- [x] 完成 F0–F4：请求身份隔离、无损路径、可取消分批加载、每标签独立状态和本地化基础。
- [x] 导航核心：每标签独立支持后退、前进、向上、刷新及 `Alt+Left`、`Alt+Right`、`Alt+Up`、`F5`、`Ctrl+R`、标准鼠标前进/后退侧键；历史仅在加载成功后提交。窗口级快捷键从 winit 原生窗口事件统一分发，不依赖 Slint 控件焦点。
- [x] 导航交互收尾：后退/前进右键历史菜单；根目录、同路径、快速连续导航、失败和取消均不产生错误历史或被迟到结果覆盖。
- [x] 智能地址栏：点击空白、`Ctrl+L`、`Alt+D` 统一进入编辑/搜索态，显示“当前完整路径 + 空格”、不全选且光标位于末尾；保留前缀搜索当前目录及子目录，删除完整前缀后全局搜索，有效路径按 `Enter` 导航。
- [x] 地址输入兼容 Windows 习惯：单独盘符补全为根目录，正反斜杠可混用，双正斜杠转为 UNC，整条路径外层引号自动去除，并通过 Windows 展开 %USERPROFILE% 等环境变量；只处理确认导航的路径候选，不改写 Everything 查询。
- [x] 地址错误可恢复：无效路径保留用户输入、上次成功列表和历史，区分路径不存在、权限不足、读取失败和位置断开；`Enter` 可重试，`Escape` 返回上次成功路径。
- [x] 路径全程保留 Windows 原始 Unicode；中文、日文、韩文、Emoji 等名称可正确显示、打开和操作，展示文本不作为文件身份。
- [x] 打开闭环：文件列表整行按 Windows 系统双击间隔识别连续点击，不依赖控件焦点或 Slint 内部双击状态；`Enter` 打开焦点项；目录进入、文件交给 Windows 默认应用打开。
- [x] 选择闭环：单选、`Ctrl+单击` 切换、`Shift+单击` 连续范围、`Ctrl+Shift+单击` 追加连续范围、选择锚点、`Ctrl+Space`、`Shift+方向键`、`Ctrl+A` 和 `Escape`；文件与文件夹行为一致，焦点、选中与悬停状态分离。
- [x] 排序闭环：名称、类型、大小、修改时间及升降序；排序入口已合并到列表表头，当前列显示方向；目录优先规则保持一致。
- [x] 页面状态完整：初始/切换加载、部分结果、空目录、权限不足、路径不存在、读取失败、位置断开和取消；错误不得伪装为空目录。权限失败作为目标目录的正式页面显示，保留目标面包屑，页面内只提供 Windows 授权入口；后退与刷新复用顶部导航。
- [x] 真实侧栏：从系统读取常用目录和本地磁盘；侧栏作为快捷入口，仅在点击和悬停时反馈，不持久高亮当前路径；支持磁盘变化刷新，不显示无真实能力的云盘、网络、标签等入口。
- [x] P0 命令区只显示已实现的选择和排序；不放新建、剪切、复制、粘贴、分享、删除等灰色占位操作。
- [x] P0 基础图标：建立最小语义映射并替换导航、标签、侧栏和通用文件的文字模拟；使用 Microsoft Fluent SVG 并记录来源与 MIT 许可。Shell 文件类型图标仍按 P1/P3 实施。
- [x] P0 基础可访问性与响应式：按钮有名称/快捷键提示，焦点可见；窄窗口保留后退、地址栏和文件名列并隐藏次要导航与低优先级列。
- [x] 会话恢复：记住窗口位置、大小、活动标签和各标签最近成功目录；不持久化运行中任务。
- [x] Agent 调试与验证：统一命令覆盖格式、静态检查、测试、无界面权限页场景和 Release 构建；状态与验证结果统一输出到 `artifacts/`。

验收：不用资源管理器辅助，可以通过鼠标和键盘连续浏览、选择并打开本地文件；快速导航、错误、取消和断开位置不破坏当前页面或历史；正式图标来源可追溯。详细逐项标准见 [ui-interaction-design.md](ui-interaction-design.md#10-p0-验收清单)。

- [x] 先统一 UI 实现：按钮、文字、面板、列表状态等复用同一组样式入口，初始值沿用当前应用效果；后续根据实际界面调整，不在实现前固定一套推测数值。
- [x] 标题栏左侧菜单打开单例设置标签；设置页采用左侧分类、右侧设置卡片的双栏布局，首期包含常规中的语言与外观中的主题。设置标签不伪装成路径、不启动目录加载、不进入关闭标签恢复或跨重启会话恢复。
- [x] 主题提供“跟随系统、浅色、深色”；跟随系统只在启动时读取，用户选择可覆盖并跨重启保留，暂不实时响应系统切换，不做高对比度模式。
- [x] 浅色与深色覆盖整个应用，包括自定义标题栏、菜单、设置页、导航、侧栏、列表、状态页和浮层；深色下背景、文字、边框、图标及各交互状态均保持清楚可辨。
- [x] 将语言切换从侧栏移入设置页，继续支持简体中文和英文并跨重启保留。
- [x] 将已验证的 Windows UI 正文字体和中文回退迁移到统一字体样式；图标字体与正文字体严格分离，并完成全页面及高 DPI 检查。
- [x] 建立独立图标目录与语义名称映射，业务页面不直接依赖图标来源路径。
- [x] 操作图标优先沿用已有 Microsoft Fluent SVG；确实缺少时才从 Files 逐项采用有明确 MIT 证据的矢量图标，并记录来源、版本、修改和许可。
- [x] 在 P1 建立独立 Windows Shell 图标模块；文件、文件夹、磁盘和已关联文件类型的图标均从 Windows Shell 动态获取，不留到 P3。
- [x] 列表先显示通用图标，后台取得系统图标后原位替换；切换目录或关闭标签时停止无用工作，旧结果不得写入新页面，已取得的图标受控复用，失败不影响浏览。
- [x] 先完成列表视图；网格、大图标等模式放到 P4。

验收：由人工在实际界面检查浅色、深色、常用缩放和窗口尺寸；样式入口已统一，主题与语言设置可保存；常用操作图标与 Windows 11 风格一致，文件类型图标和用户系统关联一致，切目录不被图标加载阻塞。
