# AsterFiles 开发任务清单

> 原则：先把本地文件管理做成可靠的日用工具，再扩展高级能力。性能专项验证暂缓，但所有阶段继续遵守“UI 线程不做磁盘工作、列表虚拟化、可取消、可见区域优先”。

前期架构切片与验收见 [foundation-plan.md](foundation-plan.md)。UI 结构、交互状态、图标边界和 P0 逐项验收见 [ui-interaction-design.md](ui-interaction-design.md)。F0–F4 已完成首个端到端版本，后续功能沿用每标签独立状态和统一 UI 意图边界。

## P0：可日用的浏览闭环

- [x] 完成 F0–F4：请求身份隔离、无损路径、可取消分批加载、每标签独立状态和本地化基础。
- [x] 导航核心：每标签独立支持后退、前进、向上、刷新及 `Alt+Left`、`Alt+Right`、`Alt+Up`、`F5`、`Ctrl+R`、标准鼠标前进/后退侧键；历史仅在加载成功后提交。
- [x] 导航交互收尾：后退/前进右键历史菜单；根目录、同路径、快速连续导航、失败和取消均不产生错误历史或被迟到结果覆盖。
- [x] 地址栏双态：成功路径显示态与路径编辑态保持统一浅色外观；`Ctrl+L` / `Alt+D` 进入路径编辑并全选；`Enter` 提交，`Escape`、取消按钮或点击地址栏外取消并恢复面包屑；当前路径不重复加载。面包屑节点负责导航，仅地址栏空白区域进入编辑。
- [x] 地址错误可恢复：无效路径保留用户输入、上次成功列表和历史，区分路径不存在、权限不足、读取失败和位置断开；`Enter` 可重试，`Escape` 返回上次成功路径。
- [x] 路径全程保留 Windows 原始 Unicode；中文、日文、韩文、Emoji 等名称可正确显示、打开和操作，展示文本不作为文件身份。
- [x] 打开闭环：文件列表整行均可双击进入目录，`Enter` 打开焦点项；文件交给 Windows 默认应用打开；鼠标与键盘调用同一应用意图。
- [x] 选择闭环：单选、`Ctrl` 切换、`Shift` 范围、选择锚点、`Ctrl+Space`、`Shift+方向键`、`Ctrl+A` 和 `Escape`；焦点、选中与悬停状态分离。
- [x] 排序闭环：名称、类型、大小、修改时间及升降序；列标题和排序命令共用状态；目录优先规则保持一致。
- [x] 页面状态完整：初始/切换加载、部分结果、空目录、权限不足、路径不存在、读取失败、位置断开和取消；错误不得伪装为空目录。
- [x] 真实侧栏：从系统读取常用目录和本地磁盘，选中状态互斥并优先匹配具体常用目录，否则显示所属磁盘；支持磁盘变化刷新，不显示无真实能力的云盘、网络、标签等入口。
- [x] P0 命令区只显示已实现的选择和排序；不放新建、剪切、复制、粘贴、分享、删除等灰色占位操作。
- [x] P0 基础图标：建立最小语义映射并替换导航、标签、侧栏和通用文件的文字模拟；使用 Microsoft Fluent SVG 并记录来源与 MIT 许可。Shell 文件类型图标仍按 P1/P3 实施。
- [x] P0 基础可访问性与响应式：按钮有名称/快捷键提示，焦点可见；窄窗口保留后退、地址栏和文件名列并隐藏次要导航与低优先级列。
- [x] 会话恢复：记住窗口位置、大小、活动标签和各标签最近成功目录；不持久化运行中任务。

验收：不用资源管理器辅助，可以通过鼠标和键盘连续浏览、选择并打开本地文件；快速导航、错误、取消和断开位置不破坏当前页面或历史；正式图标来源可追溯。详细逐项标准见 [ui-interaction-design.md](ui-interaction-design.md#10-p0-验收清单)。

## P1：视觉系统与图标

- [x] 完成 F4：简体中文/英文语言资源、统一格式化和字体回退验证。
- [ ] 建立颜色、圆角、间距、字号、阴影、动效时长等统一样式变量。
- [ ] 支持跟随系统的浅色/深色主题，并验证高 DPI。
- [ ] 正文字体使用 Windows UI 字体并验证中文回退；图标字体与正文字体严格分离。
- [ ] 建立独立图标目录与名称映射，UI 不直接依赖某个图标来源。
- [ ] 导入 Files 中明确标注 MIT 的操作类矢量图标，并保留版权声明。
- [ ] 文件、文件夹、磁盘和已关联文件类型的图标从 Windows Shell 动态获取。
- [ ] 图标分级缓存：通用图标立即显示，路径专属图标后台替换。
- [ ] 先完成列表视图；网格、大图标等模式放到 P4。

验收：常用操作图标与 Windows 11 风格一致；文件类型图标和用户系统关联一致；切目录不被图标加载阻塞。

## P2：基础文件操作

- [ ] 新建文件夹、重命名。
- [ ] 复制、剪切、粘贴，支持跨磁盘。
- [ ] 默认删除到回收站；永久删除必须二次确认。
- [ ] 冲突处理：覆盖、跳过、重命名，并支持对全部应用。
- [ ] 文件任务中心：进度、速度、剩余项、取消、失败原因与重试。
- [ ] 操作期间刷新受影响目录，不做全量无条件重载。
- [ ] 将文件操作与 UI 分离，任务失败不能卡住窗口。

验收：常见文件整理操作可可靠完成；取消和错误不会留下错误的界面状态。

## P3：Windows 原生集成

- [ ] 建立单独的 Windows 适配层，集中承载 Shell、COM 与系统调用。
- [ ] 接入系统缩略图，按可见区域优先加载并限制并发。
- [ ] 接入拖入、拖出和目录内拖放。
- [ ] 接入系统右键菜单、属性、打开方式、在终端中打开。
- [ ] 监听目录变化，外部增删改能增量反映到列表。
- [ ] 正确处理快捷方式、重解析点、长路径、隐藏项和权限边界。
- [ ] Shell 扩展异常不得拖死主界面；慢处理器需要隔离和超时策略。

验收：与 Windows 桌面、其他文件管理器和第三方 Shell 扩展协作自然。

## P4：高频效率功能

- [x] 按 F3 的标签会话边界实现，不复用窗口级单一导航状态。
- [ ] 多标签页：新建、关闭、恢复关闭、拖动排序和会话恢复。
- [ ] 收藏/固定目录，侧栏支持拖动排序。
- [ ] 视图模式：详细信息、列表、网格；每个目录记忆设置。
- [ ] 快速过滤当前目录；全盘索引和内容搜索仍不做。
- [ ] 批量重命名与操作预览。
- [ ] 可选双栏模式，共享文件任务中心但保持独立导航历史。
- [ ] 预览面板先支持图片、文本和常见媒体元数据。

验收：覆盖个人日常整理和开发目录操作，重度任务不必切回资源管理器。

## P5：稳定性、无障碍与交付

- [ ] 键盘完整可用，补齐屏幕阅读器语义、对比度与焦点可见性。
- [ ] 记录可读日志与崩溃信息，不记录完整私人路径作为默认遥测。
- [ ] 覆盖空目录、超大目录、移动硬盘、UNC 路径、断开的盘和权限错误。
- [ ] 覆盖简繁中文、组合字符、Emoji、超长名称，以及无法无损转换为 UTF-8 的 Windows 文件名。
- [ ] 建立单元测试和关键端到端测试，尤其覆盖取消、冲突和失败恢复。
- [ ] 生成便携包与安装包；签名和自动更新在发布给他人前再加入。
- [ ] 维护第三方许可清单，图标资产来源可追溯。

验收：异常路径可诊断、可恢复，安装和卸载不破坏用户数据。

## P6：性能回归门槛（功能稳定后执行）

- [ ] 固化冷启动、首批可见项、目录切换取消延迟、滚动帧时间和峰值内存指标。
- [ ] 建立 1 千、1 万、10 万项测试目录与机械硬盘/SSD 场景。
- [ ] 检查图标/缩略图队列积压、缓存命中率和切目录后的无效工作。
- [ ] 将当前手感良好的 release 构建保存为比较基线。

验收：新增功能不能显著破坏当前已认可的响应速度。

## 后置范围

- FTP、SFTP、WebDAV、S3 和云盘协议；
- 全盘索引与内容搜索；
- 插件系统；
- 替换 Windows Explorer Shell。

网络功能开始前只保留清晰的边界，不提前建设通用提供者框架。

## 推荐实施顺序

严格按 `P0 → P1 → P2 → P3 → P4 → P5 → P6` 推进。每个阶段只同时打开一个纵向功能：从核心逻辑、后台任务、界面状态到错误处理完整跑通后，再进入下一项。
