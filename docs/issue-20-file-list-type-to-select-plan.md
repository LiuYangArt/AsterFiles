# Issue #20：文件列表直接键入定位方案

GitHub Issue：[支持 Explorer 风格的文件列表直接键入定位](https://github.com/LiuYangArt/AsterFiles/issues/20)

## 1. 结论

文件列表获得键盘焦点时，直接输入字母或数字，按 Windows File Explorer 的习惯在当前列表内定位名称前缀匹配项，不隐式启动 Everything 搜索。

Everything 仍由地址栏、`Ctrl+F` 等明确搜索入口触发。这样可以保留当前目录、排序、选择和滚动上下文，也不会把一个即时键盘动作变成后台索引请求。

## 2. 交互规则

- 单独输入一个字符：从当前焦点之后开始，按当前显示顺序查找名称以该字符开头的条目；到列表末尾后从开头继续。
- 短时间连续输入多个字符：组成名称前缀，例如依次输入 `a`、`b` 定位 `ab...`。
- 连续重复同一个字符：在该字符开头的条目之间向后循环，而不是把输入解释为 `aaa...`。
- 匹配忽略大小写；数字与字母使用同一规则。
- 命中后条目获得焦点、成为唯一选择和范围选择锚点，并滚入可见区域。
- 无匹配时保持原有焦点、选择、锚点和滚动位置，不显示搜索页或错误页。
- 输入超时后，下一次字符开始新的匹配串。超时时长作为应用内固定交互常量，不增加用户设置。
- `Escape` 清空待匹配输入；若同时存在其他更高优先级状态，继续沿用现有退出顺序。

## 3. 焦点与输入优先级

该行为只在文件列表是当前键盘操作目标时生效。以下情况不得截获字符：

- 地址栏或其他搜索输入正在编辑；
- 文件或文件夹正在重命名；
- 设置页、菜单搜索或其他文本输入获得焦点；
- 中文输入法等输入法正在组合输入；
- `Ctrl`、`Alt` 或 Windows 键参与快捷键；
- 当前按键属于已有窗口级快捷键。

切换标签、导航、刷新、切换视图、进入文本编辑、窗口失焦或离开文件列表焦点域时，清空旧输入，避免跨上下文误匹配。

## 4. 当前列表范围

普通目录按当前排序、分组和视图投影顺序匹配。组标题不参与匹配。

Everything 搜索结果同样只在当前搜索结果页面内定位，不提交新查询。对于稀疏分页，只匹配已经加载到当前模型的真实条目；未加载占位行不参与，也不为定位而强制拉取远端页或完整结果。

列表加载期间允许匹配已经到达的条目。后续批次到达不主动改变当前命中；用户再次键入时再基于最新模型查找。

## 5. 状态与架构边界

- 输入缓冲和最近匹配位置属于窗口级短暂交互状态，不写入标签会话或磁盘。
- 匹配使用展示名称进行比较，但命中、选择、滚动和后续操作始终使用稳定 `EntryId` 与 Rust 原始路径。
- 直接键入不创建 `RequestId`，不读取文件系统、元数据、Shell/COM、网络或 Everything IPC。
- 不改变路径、历史、排序、分组、筛选、视图或搜索范围。
- 普通目录、Everything 稀疏结果和各视图复用同一个“按稳定身份聚焦并滚入可见区”入口，不维护分叉选择状态。
- 新增用户可见提示或可访问文案必须进入现有简体中文和英文资源；首版不增加常驻提示或设置项。

## 6. 实施切片

1. 定义窗口级直接键入状态：缓冲、最后输入时间、循环字符和上下文代次。
2. 在窗口级键盘入口完成焦点域、文本编辑、输入法和快捷键分流。
3. 基于当前投影顺序实现前缀匹配、同字符循环和首尾回绕。
4. 命中后复用现有稳定身份选择、焦点、锚点和滚入可见区链路。
5. 接入标签、请求、视图、焦点与窗口生命周期的状态清理。
6. 补齐普通目录、分组投影、Everything 稀疏模型和不同视图的自动验证。

## 7. 自动验证

至少覆盖：

- 单字符、连续前缀、同字符循环、首尾回绕、大小写和数字；
- 从当前焦点之后查找、无焦点时从列表开头查找；
- 无匹配不改变选择、焦点、锚点和滚动位置；
- 当前排序、分组和视图投影顺序，组标题不参与；
- Everything 已加载真实结果可匹配，未加载占位不匹配且不产生搜索请求；
- 超时、`Escape`、标签切换、导航、刷新、视图切换和窗口失焦清空状态；
- 文本编辑、输入法组合输入和带修饰键的快捷键不误触；
- 命中始终使用稳定条目身份，不把展示名称当作文件操作路径。

实现完成后运行：

```powershell
python tools/verify.py
cargo build
```

机器可读汇总保留在 `artifacts/verify/summary.json`。交付时报告 `target/debug/asterfiles.exe` 的修改时间与 SHA-256。用户确认 Issue 完成前不构建 Release。

## 8. 人工验收

项目规则禁止 Codex 操作 AsterFiles UI。用户需在真实窗口检查：

- 字母、数字、连续前缀和同字符循环的键盘手感；
- 普通目录与 Everything 搜索结果；
- 详细信息、列表、网格及分组后的顺序；
- 地址栏、重命名、设置输入和中文输入法不会误触；
- 快速切换标签、导航、刷新和窗口失焦后不会沿用旧前缀；
- 大目录分批加载与 Everything 深度滚动时，不出现卡顿、隐式搜索或错误跳转。
