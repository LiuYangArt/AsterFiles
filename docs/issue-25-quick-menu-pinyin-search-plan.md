# Issue #25：右键快速菜单拼音搜索方案

GitHub Issue：[支持右键快速菜单的中文全拼与简拼搜索](https://github.com/LiuYangArt/AsterFiles/issues/25)

## 1. 结论

右键快速菜单增加中文无声调全拼和拼音首字母搜索。例如“粘贴”可由 `粘贴`、`zhantie`、`zt` 命中；含“终端”的命令可由 `终端`、`zhongduan`、`zd` 命中。

该能力只扩展现有内存过滤，不改变菜单加载、排序、展开或命令执行方式。中文原文、英文标签和 Shell verb 的现有匹配继续保留。

## 2. 产品规则

- 全拼、简拼和普通拉丁字母匹配均忽略大小写。
- 匹配 AsterFiles 自有命令、Windows Shell 命令及第三方扩展已经加载的中文标题。
- 结果保持原菜单顺序；不做相关度重排、模糊纠错、同音词扩展或历史权重。
- 清空输入后恢复完整菜单及原分隔线结构。
- 首版只搜索当前层已经加载的项目；未展开、未加载的子菜单不参与，不因搜索而自动展开或预加载。
- 禁用项是否显示继续沿用当前过滤规则，拼音能力不改变其可执行状态。

## 3. 实现选择

采用维护中的 Rust 库 `ib-pinyin`，只启用无声调全拼和首字母两种记法。该库直接支持全拼、简拼、多音字及混合文本匹配，适合 Windows 与第三方扩展返回的任意中文标题；不自行维护拼音表，也不增加 Windows 平台 API 耦合。

拼音匹配保持在应用层的菜单模型过滤中：

- 每次非空查询只创建一个拼音匹配器，并复用于本次已加载菜单行的遍历；
- 现有唯一匹配入口统一判断显示文字、Shell verb、全拼和简拼；
- 查询为空时不建立拼音匹配器，直接沿用当前完整投影；
- 匹配仍是纯内存工作，不访问 Shell、文件系统、网络或 Everything；
- 显示标题和拼音只参与筛选，命令执行继续使用原始 command ID。

具体结构以实现时验证的库接口为准。优先封装为独立的小型菜单文本匹配模块，避免把拼音细节散落到 Shell/COM 或 Slint 层；不增加设置项、兼容层、迁移或 fallback。

## 4. 性能边界

快速菜单通常只有少量项目，但过滤由每次文本编辑同步触发。实现需要满足：

- 每次输入只创建一次查询匹配状态并遍历已加载行；菜单规模较小，若基准测试显示问题再依据实测优化，不增加第二套拼音索引；
- 不在 UI 线程读取目录、元数据、注册表、Shell/COM 或网络；
- 子菜单新加载的行直接使用同一个匹配入口，不回扫或重建其他会话；
- 不改变现有每窗口菜单状态、快照隔离和 Shell 会话生命周期。

## 5. 实施切片

1. 加入并锁定 `ib-pinyin` 依赖，确认许可证与最低 Rust 版本符合项目。
2. 建立菜单文本匹配封装，覆盖普通文本、全拼与简拼。
3. 让内置命令、Shell 顶层项目和已加载子菜单统一经过同一个匹配入口。
4. 把现有过滤入口切换到统一匹配器，保留分隔线整理、活动项和原始 command ID 行为。
5. 扩展单元测试及 `quick-menu-search` 无界面状态证据。
6. 更新 Windows Shell 菜单说明与任务状态；完成后执行统一验证和 Debug 构建。

## 6. 自动验证

至少覆盖：

- `粘贴`、`zhantie`、`zt`、`ZHANTIE` 均命中“粘贴”；
- `终端`、`zhongduan`、`zd` 命中包含“终端”的命令；
- 中英文混合标题、英文大小写和 Shell verb 继续命中；
- 多音字标题至少验证库支持的任一合理读音，不自行覆盖所有语义读音；
- 不完整或无关拼音不误命中，空结果保持为空；
- 过滤后首尾与重复分隔线继续被清理；
- 命中行保留原 id、node id、Shell 标记、启用状态和原始 command ID；
- 过滤不产生 Shell、文件系统、网络或 Everything 请求；
- 顶层和已加载子菜单使用同一匹配规则，未加载子菜单不参与。

实现完成后运行：

```powershell
python tools/verify.py
cargo build
```

机器可读汇总保留在 `artifacts/verify/summary.json`。交付时报告 `target/debug/asterfiles.exe` 的修改时间与 SHA-256。用户确认 Issue 完成前不构建 Release。

## 7. 人工验收

项目规则禁止 Codex 操作 AsterFiles UI。用户需在真实窗口检查：

- 中文输入法原文输入、英文全拼、简拼、粘贴和退格的连续手感；
- 自有中文命令、Windows 中文命令和至少一个第三方中文菜单项；
- 大小写输入、空结果、清空恢复及方向键和 Enter 执行；
- 搜索期间菜单无明显卡顿，命令执行目标没有串项；
- 未展开子菜单不会被搜索自动加载，展开后已加载项目可按既定当前层规则搜索。

用户确认 Issue 完成后，再按项目规则构建 Release 并报告时间与 SHA-256。

## 8. 非目标

- 双拼、声调、模糊拼写、同音词、自然语言或智能排序；
- 递归搜索所有子菜单，或为搜索提前初始化第三方动态菜单；
- 文件列表直接键入定位、Everything 文件搜索或其他输入框；
- 新的用户设置、索引、网络服务或后台进程。
