# P3 Windows 原生集成决策摘要

> 日期：2026-08-31
> 状态：产品范围已确认，可以开始实施

## 1. 推进结论

P3 已有足够信息开始实施。先完成 Windows 文件拖放，再处理目录变化监听、文件显示边界以及长路径、重解析点和权限边界。

右键菜单不属于 P3。当前“显示完整经典菜单”保持原样，菜单加载、第三方扩展隔离、超时、诊断和菜单形态统一移入独立的 [Windows Shell 菜单集成 Feature](windows-shell-menu-feature.md)，待设计充分后再实施。

系统缩略图也不属于 P3，整体移到 P4，与列表、网格和大图标视图统一设计。

## 2. P3 范围

P3 包含：

- 桌面、Explorer 与 AsterFiles 之间双向拖放真实文件和文件夹；
- 应用内把文件拖到当前目录或子文件夹；
- 拖入复用 P2 任务中心的复制、移动、冲突、进度、暂停、取消和失败重试；
- 监听外部文件变化，使其他程序造成的增删改反映到相关标签；
- 分别控制隐藏文件与系统文件的显示；
- 补齐长路径、重解析点、断开位置和权限边界。

P3 不包含：

- 右键菜单改造、第三方 Shell 扩展隔离或菜单兼容性强化；
- 系统缩略图；
- 网格和大图标视图；
- 虚拟文件、非文件系统 Shell 对象；
- 远程文件拖出前自动下载；
- 拖放撤销。

菜单与上述 P3 能力不存在实施依赖。拖放虽然也使用 Windows Shell/OLE，但使用独立接口和模块，不要求先改变现有右键菜单。

## 3. 已确认的产品行为

### 3.1 文件拖放

- 同一磁盘默认移动，跨磁盘默认复制。
- `Ctrl` 强制复制，`Shift` 强制移动，`Alt` 或 `Ctrl+Shift` 创建快捷方式。
- 可放到当前目录空白处或文件夹行；普通文件行不作为目标文件夹。
- 拖到自身或自身子目录时明确显示禁止。
- 文件夹目标显示悬停反馈；靠近列表边缘时受控滚动，但不自动进入文件夹。
- 拖入 AsterFiles 的任务使用现有任务中心；拖出到 Explorer 后由 Explorer 负责进度和冲突。
- 操作结束后更新所有显示受影响目录的标签。外部目标没有可靠返回结果时只刷新相关源目录，不推测移动成功。

完整拖放设计继续以 [P3 Windows 文件拖放实施方案](p3-windows-drag-drop-plan.md) 为准。

### 3.2 隐藏文件与系统文件

菜单提供两个互相独立的开关：

- 显示隐藏文件：默认开启；
- 显示系统文件：默认关闭。

分类使用 Windows 文件属性。显示后采用普通文件行样式，不使用半透明或其他弱化效果。两项设置应持久化，并对所有普通目录标签生效。

### 3.3 系统缩略图

系统缩略图整体移到 P4，与详细信息、列表、网格和大图标视图一起设计，行为跟随 Windows Explorer。P3 继续使用现有 Windows Shell 文件类型图标，不额外制作详细列表的小缩略图链路。

## 4. 由实现方案确定的事项

以下属于技术设计，不需要用户另行补充：

- OLE 拖放所在的 STA/窗口线程、注册和释放时机；
- 原生拖放事件到 Slint 命中区域的桥接；
- 同卷判断、目标能力协商和后台预检查；
- 拖出结果不可靠时的保守刷新策略；
- 目录监听的事件合并、重命名配对、缓冲区溢出和断盘恢复；
- 长路径、其余重解析点、UNC 和权限错误的测试矩阵。

所有实现继续遵守：原始路径身份不得由展示文字重建；UI 线程不读取磁盘或调用 Shell/COM；结果按标签和请求身份隔离；后台任务可取消且迟到结果不得覆盖新页面。

## 5. 推荐实施顺序

1. P3.D0：原生拖放底座和可读取状态；
2. P3.D1：从桌面/Explorer 拖入当前目录；
3. P3.D2：文件夹目标、应用内拖放、边缘滚动和路径保护；
4. P3.D3：拖出到 Explorer；
5. P3.D4–D5：快捷方式、反馈、日志和人工验收；
6. 目录变化监听；
7. 隐藏文件、系统文件及其他路径边界。

每次只推进一个完整纵向切片。系统缩略图在 P4 视图模式切片中统一实施。菜单 Feature 不阻塞 P3，也不随 P3 顺带修改。

## 6. 完成后的用户效果

P3 完成后，用户可以像使用 Explorer 一样在桌面、Explorer、AsterFiles 和应用内文件夹之间拖动真实文件；拖入任务沿用现有进度和冲突处理，外部文件变化会自动反映到相关标签。隐藏文件默认可见，系统文件按需开启。当前右键菜单和“显示完整经典菜单”行为保持不变。
