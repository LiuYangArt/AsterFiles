# Everything 集成设计

## 1. 目标与范围

将 Everything 作为 AsterFiles 的本地索引服务，首个版本完成三项能力：

1. 在设置页配置、发现并验证 Everything；
2. 将地址栏扩展为同时支持路径导航和 Everything 搜索的智能地址栏；
3. 使用 Everything 已维护的索引显示文件大小和本地、已索引网络位置的文件夹大小。

AsterFiles 不移植 Everything 索引核心，不进行全盘递归搜索，也不在 Everything 不可用时退回现场递归计算文件夹大小。普通目录浏览和 UNC 路径导航不依赖 Everything，仍由现有目录加载链路完成。

首版以 Everything 1.5 x64 为目标。本机开发默认路径为：

```text
C:\Program Files\Everything 1.5a\Everything64.exe
```

产品不能只依赖该固定路径；设置首次打开时应通过注册表、常见安装位置和正在运行的实例自动发现，并允许用户覆盖。

## 2. 用户行为

### 2.1 设置页

设置页增加“Everything”分类，包含：

- Everything 程序路径：自动发现后预填，可浏览选择；
- 实例：默认使用发现到的 1.5a 实例，高级区域允许指定非默认实例；
- 连接状态：未配置、未运行、连接中、可用、版本不支持、连接失败；
- 连接信息：程序版本、实例名称、索引能力和文件夹大小索引状态；
- “测试连接”操作；
- “启动 Everything”操作，仅在路径有效但实例未运行时显示或启用。

保存配置前必须完成格式校验；连接测试成功后保存已确认的程序路径和实例，后续正常查询稳定使用同一实例。只有首次配置、用户清除配置或已保存连接失效时才重新自动发现，不能在每次查询中依次猜测多个实例。

Everything 不可用时，搜索与索引大小明确显示原因，不静默退回慢速磁盘扫描。路径导航和普通目录浏览保持可用。

### 2.2 智能地址栏

地址栏保留面包屑显示与统一智能编辑两种行为：

- 点击面包屑节点：直接导航到对应目录；
- 点击地址栏空白、`Ctrl+L` 或 `Alt+D`：调用同一个智能编辑状态转换，显示“当前完整路径 + 一个空格”，不全选，光标位于末尾；
- 按 `Escape`：取消智能编辑并恢复面包屑与当前目录列表；
- 输入或保留有效路径后按 `Enter`：进入该目录；
- 其余内容按 `Enter`：作为 Everything 查询并把焦点移到结果列表。

通过三种入口进入智能编辑态时，均显示“当前路径 + 一个空格”，不全选，光标放在末尾。例如：

```text
D:\Assets *.blend size:>100mb
```

保留进入搜索态时的完整路径前缀，默认表示搜索当前目录及全部子目录。地址栏左侧固定范围图标支持点击或单独按 `Tab`，在 `ancestor:` 递归范围与 `parent:` 仅当前目录范围间切换并立即重搜。用户清除该前缀后，查询变为全局搜索；图标保留占位但禁用变暗。路径本身可能包含空格、括号或 Everything 操作符字符，因此不能按第一个空格拆分；应用必须单独保存搜索范围、搜索深度和用户查询，并只在展示层组合范围与查询。

搜索输入采用短防抖后即时提交。快速继续输入、导航、关闭标签或退出时取消旧查询，迟到结果不得更新页面。

### 2.3 Everything 查询语法

路径范围由 AsterFiles 构造为受保护的条件，用户输入部分原样保留 Everything 高级语法，例如：

```text
*.blend size:>100mb
ext:png|jpg dm:thisweek
```

实现不得通过字符串拼接制造含义不明确的查询。应先转义或引用范围路径，再与用户表达式组合；路径中的空格、引号、括号、`!`、`|` 等字符不能改变查询含义。

如果整段输入可能同时是路径和搜索表达式，只有用户按 `Enter` 时才在后台验证其是否为可导航路径；实时输入阶段不反复访问文件系统。验证成功则导航，失败则维持搜索，不把“路径不存在”错误页覆盖搜索结果。

## 3. 搜索结果页面

搜索结果复用文件列表的选择、打开、右键菜单和文件操作能力，但使用独立的列表模式和列配置：

- 名称；
- 路径：显示条目的父目录，不重复文件名；
- 大小；
- 修改时间。

普通目录列表继续显示“名称、类型、大小、修改时间”。搜索模式和普通目录模式分别保存列顺序与列宽，互不覆盖。搜索结果的排序优先由 Everything 完成；是否需要本地二次排序必须由原型测量后决定，不能等待完整结果再一次性显示。

搜索结果分批提交并严格虚拟化。每条结果在 Rust 中保存原始 `PathBuf/OsString` 或稳定结果 ID；名称和父目录只是展示文字，打开、重命名、删除和右键菜单不得从显示字符串反向重建路径。

搜索页面至少具有以下状态：

- 等待输入；
- 搜索中；
- 部分结果；
- 完成；
- 无结果；
- Everything 未配置或未运行；
- 当前范围未被索引；
- 查询语法错误；
- 查询超时或连接中断。

状态栏显示结果数量；大小总计只有在 Everything 能可靠返回且无需阻塞首批结果时才显示。

## 4. 本地路径与 UNC 网络路径

### 4.1 本地路径

本地 NTFS/ReFS 位置使用 Everything 对应索引。当前路径范围搜索包括该目录及全部子目录。路径未被索引时，提示“此位置未被 Everything 索引”，不退回递归枚举。

### 4.2 UNC 路径

例如：

```text
\\LiuYanghomeNAS\Multimedia
```

UNC 路径不会与 Everything 语法冲突，因为应用不会把“路径 + 空格 + 查询”当成一段待拆分字符串：

- 路径导航始终由 AsterFiles 现有后台目录链路处理，与 Everything 无关；
- 搜索态单独保存 UNC 范围和用户查询，提交前对范围进行引用或转义；
- UNC 范围搜索仅在该共享已加入 Everything 的文件夹索引或网络索引时可用；
- 未索引时显示明确提示，并提供在 Everything 中配置网络路径的说明；
- 不对 NAS 发起隐藏的递归搜索或文件夹大小扫描。

网络共享使用 Everything 文件夹索引时，更新速度可能慢于本地 NTFS 索引。界面应描述为“索引结果”，不能暗示绝对实时。

## 5. 文件和文件夹大小

### 5.1 文件大小

普通目录枚举已能读取文件大小；Everything 搜索结果直接请求索引中的大小字段。搜索结果不再为每个文件额外读取元数据。

### 5.2 文件夹大小

普通目录列表先分批显示名称等已有信息，文件夹大小初始为空或显示“查询中”。随后只为当前可见及即将可见的文件夹提交后台查询：

1. 使用完整原始路径查询 Everything 文件夹大小索引；
2. 结果按 `TabId + RequestId + EntryId + 原始路径` 回填；
3. 导航、刷新、关闭标签或条目身份变化后丢弃旧结果；
4. 同一目录内采用有界短期缓存，目录刷新或相关文件变化后失效；
5. 本地重解析点可解析真实路径后最多重试一次；
6. 未索引、超时或不可用时显示对应状态，不递归计算。

`0` 字节必须与“未索引”区分。重解析点、离线网络位置和权限失败不能伪装成空文件夹。

文件夹大小首版支持本地路径，以及已被 Everything 明确索引的 UNC 路径；不支持未索引网络位置。是否批量查询、可见区域预取数量和并发上限由原型性能数据确定，不为列表中的每个文件夹创建连接或启动进程。

## 6. 架构与数据流

```text
Slint：设置、智能地址输入、搜索结果、大小占位
                        ↓ UI 意图 / 展示模型
应用协调层：TabId、RequestId、搜索范围、结果身份、取消
                        ↓
Everything 适配层：发现、连接、查询、结果转换、超时
                        ↓
Windows Everything SDK / IPC 与已运行的 1.5 实例
```

新增独立的 Everything 适配层，Windows 实现放在 `platform/windows` 边界内。UI 不直接加载 DLL、发送 IPC、探测进程、检查路径或读取索引。

建议核心模型：

- `EverythingConfig`：程序路径、实例、已验证版本；
- `EverythingStatus`：连接和能力状态；
- `SearchScope`：全局或原始目录路径；
- `SearchRequest`：`TabId + RequestId + SearchScope + 用户表达式 + 排序 + 分页/批次信息`；
- `SearchResult`：稳定结果 ID、原始完整路径、原始名称、父目录、类型、大小和修改时间；
- `FolderSizeRequest`：`TabId + RequestId + EntryId + 原始路径`。

搜索与目录加载可以共享标签的最新 `RequestId` 规则，但必须区分页面来源；同一标签只有最新页面请求可以更新列表。文件夹大小依附于产生条目的目录请求。Everything 工作不得占住目录枚举、Shell 图标或文件操作的唯一线程。

## 7. 连接方式与生命周期

首个技术原型应比较官方 SDK DLL 与直接 IPC 的实际能力后确定最终方式，选择标准是：

- 能返回名称、父路径、大小、修改时间和文件/目录类型；
- 支持 1.5 实例选择、错误码、超时、取消和分批结果；
- 能稳定查询文件夹大小索引；
- 不要求 UI 消息循环承担可能阻塞的工作；
- x64 分发边界和许可清楚。

最终只保留一种正式连接实现，不长期维护 SDK 与 IPC 双后端。连接按应用生命周期复用，不为每次搜索或每个文件夹重新连接。Everything 退出或重启后进入断开状态，由下一次明确重连或有限重试恢复；不能无限重试或冻结页面。

如果随 AsterFiles 分发官方 SDK DLL，则 DLL 路径由应用固定管理，不要求普通用户配置。设置页的“Everything 路径”指程序路径，不把内部 DLL 暴露为常规设置。

## 8. 配置与持久化

Everything 配置属于应用级设置，不属于标签会话。保存内容至少包含：

- 可执行文件原始路径；
- 实例名称；
- 最近一次验证成功的版本；
- 是否允许 AsterFiles 在需要时启动 Everything。

不保存搜索运行中的 `RequestId`、连接句柄或后台任务。搜索历史、是否恢复搜索页和每标签搜索列配置首版不自动扩展；列配置可作为应用级“搜索列表布局”保存。

程序路径失效时保留用户配置并显示错误，不能静默改用另一个实例。用户选择“重新发现”后才替换。

## 9. 错误与安全边界

- Everything 未安装：说明需要 Everything 1.5，并提供设置入口；
- 程序未运行：允许按配置启动，失败时显示系统原因；
- 版本或位数不兼容：拒绝连接并给出所需版本；
- 实例不匹配：提示选择或重新发现，不循环猜测；
- 查询语法错误：保留输入和上次可用页面，标出查询问题；
- 连接超时：取消当前请求，允许重试；
- 路径未索引：区分本地未收录、UNC 未配置和文件夹大小未启用；
- 搜索结果指向已删除文件：操作时由现有文件操作链路报告目标不存在并定向刷新；
- 默认日志不记录完整私人查询和完整路径，只记录请求身份、耗时、数量、状态码和经过裁剪/散列的诊断信息。

AsterFiles 不修改 Everything 的索引配置。对于未索引 UNC，只提供操作说明或打开 Everything 设置的入口；是否自动写配置不在首版范围。

## 10. 性能与取消

- 输入防抖建议初值为 120–200 毫秒，最终以真实手感验证；
- 首批搜索结果应尽快显示，不等待全部结果；
- 首版单次查询硬限制为 256 行；第一批立即替换目录投影，状态栏显示“已显示前 N 项，共 M 项”，不后台拉取全部命中；后续滚动分页必须由接近列表末尾的明确请求触发；
- 列表必须保持虚拟化，不一次创建大量 UI 节点；搜索排序字段/方向直接映射为 Query2 `sort_type`，表头箭头、服务端稳定排序和后续 offset 分页必须一致，不在客户端二次排序；
- 新查询取消旧查询，旧批次按 `TabId + RequestId` 丢弃；
- 文件夹大小只查询可见区域及小范围预取；
- 所有 IPC 设置有限超时并运行在后台；
- Everything 查询队列与目录读取、Shell 图标、文件操作工作池隔离。

## 11. 无障碍与本地化

新增可见文案全部进入简体中文和英文资源，包括设置分类、连接状态、未索引、语法错误、搜索范围、查询中和文件夹大小状态。地址栏无障碍名称应随模式变化，屏幕阅读器能区分“路径输入”和“搜索”。搜索结果的路径列应有完整内容提示，截断显示不能成为唯一访问方式。

### E2：智能地址栏与搜索结果

- 引入统一智能地址栏状态模型，不为快捷键保留独立路径编辑分叉；

验收：输入有效路径可导航；其他输入即时搜索；删除范围前缀后全局搜索；迟到结果不能污染新页面。

### E3：文件夹大小

## 13. 验证要求

自动验证至少覆盖：

- 路径与用户查询的组合、引用和特殊字符；
- 路径中含空格、中文、Emoji、括号和 Everything 操作符；
- `\\LiuYanghomeNAS\Multimedia` 的导航、已索引搜索和未索引状态；
- 有效路径按 `Enter` 导航，普通表达式保持搜索；
- 当前范围、全局范围与高级语法；
- 快速连续查询的取消和迟到结果丢弃；
- 多标签请求隔离；
- 搜索结果原始路径身份；
- 文件夹大小零值、未索引、超时和过期回填；
- Everything 未运行、实例错误、重启和连接恢复；
- 中英文资源完整性。

人工验证使用真实 Everything 1.5、包含大量结果的本地磁盘、带空格与特殊字符的目录，以及可访问的 NAS 共享。日志写入 `artifacts/logs/`，状态导出写入 `artifacts/state/`，截图写入 `artifacts/ui/`，性能数据写入 `artifacts/perf/`；统一验证继续使用 `python tools/verify.py`。

## 14. 非目标

首版不包含：

- 自建全盘索引或内容索引；
- Everything 不可用时的递归搜索回退；
- 未索引目录的现场文件夹大小计算；
- 自动修改 Everything 索引配置；
- 非 Windows 平台实现；
- ETP 远程服务器、互联网搜索或通用网络搜索框架；
- 搜索历史、保存搜索、复杂筛选器界面和搜索建议；
- 从 Everything 展示字符串重建文件身份。

## 15. 已确认决策

- 搜索结果“路径”列显示父目录；名称列直接请求 Query2 `HIGHLIGHTED_NAME` 并解析官方 `**` 字面星号与 `*text*` 高亮标记，范围前缀不参与标记，原始名称与路径身份不变；名称单元格始终左对齐：图标固定在列左侧，普通目录名称或搜索高亮片段紧贴图标连续排版；名称严格裁剪在扣除图标、内边距和列间固定空间后的单元格内，超长名称显示省略号且完整名称继续用于无障碍；
- 点击面包屑继续导航；点击地址栏空白、`Ctrl+L`、`Alt+D` 以相同行为进入智能编辑态；
- 地址栏输入有效路径并按 `Enter` 后进入目录；
- 当前路径范围包含全部子目录；
- 删除当前路径前缀后执行全局搜索；
- Everything 高级语法原样支持；
- UNC 导航不依赖 Everything，UNC 搜索和文件夹大小要求已索引；
- Everything 不可用或未索引时不提供递归回退。
